# 贡献流程

欢迎提交 Issue 和 Pull Request！

## 贡献流程

**务必阅读[贡献规范](./contribution-guide.md)。**

1. Fork 本仓库
2. 创建功能分支（`git checkout -b feature/your-feature`）
3. 提交更改（`git commit -m 'feat: add some feature'`）
4. 推送分支（`git push origin feature/your-feature`）
5. 发起 Pull Request

::: tip 完整指引
更多环境配置与构建命令细节，见仓库根目录的 [CONTRIBUTING.md](https://github.com/The-Brotherhood-of-SCU/Bugaoshan/blob/main/CONTRIBUTING.md) 与 [AGENTS.md](https://github.com/The-Brotherhood-of-SCU/Bugaoshan/blob/main/AGENTS.md)。
:::
